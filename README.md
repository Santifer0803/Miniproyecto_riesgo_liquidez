## Paquetes requeridos

* bslib: Carga temas para la aplicación.
* janitor: Limpia los nombres de las columnas
* knitr: Personalización de las tablas.
* plotly: Gráficos interactivos.
* readxl: Creación y lectura de archivos de Excel.
* shiny: Para crear la aplicación.
* tidyverse: Gráficos, manejo de *dataframes*, fechas y múltiples manipulaciones de los datos.
* here: Para marcar directorios locales.
* DT: Tablas interactivas.

## Instrucciones de ejecución

Para encontrar el programa cargue el Rproject, abra la carpeta dashboard y, seguidamente, el documento app.R.

Una vez que se tiene la app abierta, se debe seleccionar **todo** el código manualmente y correrlo con CTRL + ENTER.

**ADVERTENCIA**: La aplicación tiene dependencias con archivos externos, por lo cual, oprimir el botón de *Run App* resultaría en múltiples errores, aunque la aplicación corra.
